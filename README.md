## О проекте

TableFlow - это современное веб-приложение для управления данными, которое превращает хаос Excel-файлов в структурированные базы данных с удобным веб-интерфейсом. Решение создано специально для команд и организаций, которые работают с табличными данными и нуждаются в централизованном управлении информацией.

### Основная проблема

Многие компании до сих пор используют Excel-файлы для совместной работы, что приводит к:

- Потерям данных при одновременном редактировании
- Конфликтам версий файлов
- Несогласованности информации
- Отсутствию централизованного доступа
- Сложности в поиске и фильтрации данных

### Наше решение

TableFlow предоставляет единую платформу для:

- Импорта данных из Excel/CSV файлов
- Создания структурированных таблиц с типизированными полями
- Совместной работы с данными в реальном времени
- Продвинутого поиска и фильтрации
- Экспорта данных в различных форматах

## Установка и запуск

### Быстрый старт

1. Клонируйте репозиторий или скачайте файлы
2. Откройте `index.html` в современном браузере
3. Начните работу с готовыми шаблонами или импортируйте свои данные

### Требования

- Современный веб-браузер (Chrome 70+, Firefox 65+, Safari 12+)
- JavaScript включен
- Поддержка LocalStorage (для сохранения данных)

### Развертывание и получение файлов

#### Локальное развертывание:

- **Для демо/хакатона**: Откройте `tableflow-standalone.html` (работает без интернета)
- **Полный сервер**: `python local-server.py` → `http://localhost:8080`
- **Простой веб-сервер**: `python -m http.server 8000`

#### Продакшен:

- **Статический хостинг**: GitHub Pages (наш выбор), Netlify, Vercel
- **Веб-сервер**: Apache, Nginx с `local-server.py` как бэкенд
- **Docker**: Используйте прилагаемый Dockerfile

## Руководство пользователя

### Первые шаги

1. **Создание первой таблицы**:

   - Выберите готовый шаблон в разделе "Шаблоны"
   - Или импортируйте данные из Excel/CSV файла

2. **Работа с данными**:

   - Используйте поиск для быстрого нахождения записей
   - Применяйте фильтры для отбора данных по критериям
   - Редактируйте записи прямо в таблице

3. **Экспорт результатов**:
   - Выберите нужный формат (Excel, CSV, JSON)
   - Настройте параметры экспорта
   - Скачайте готовый файл

## 🔧 Техническая реализация

### Хранение данных

- **LocalStorage**: Клиентское хранение всех данных
- **JSON формат**: Структурированное представление таблиц
- **Версионирование**: Отслеживание изменений структуры
- **Миграции**: Обновление формата данных при изменениях

### Обработка файлов

- **Chunked loading**: Порционная загрузка больших файлов
- **Web Workers**: Асинхронная обработка данных
- **Memory management**: Эффективное использование памяти
- **Error handling**: Корректная обработка ошибок

### Производительность

- **Виртуализация**: Рендеринг только видимых строк
- **Debouncing**: Оптимизация поиска и фильтрации
- **Lazy loading**: Отложенная загрузка компонентов
- **Caching**: Кэширование вычислений и результатов
